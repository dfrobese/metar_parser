# Contributing

Thanks for contributing to metar_parser_dart.

## Setup

1. Install Dart SDK (or Flutter SDK if your workflow uses Flutter tooling).
2. Install dependencies:

```bash
flutter pub get
```

3. Run tests:

```bash
flutter test
```

4. Run analyzer:

```bash
flutter analyze
```

## Pull Requests

- Keep PRs focused and small.
- Add or update tests for behavior changes.
- Update `CHANGELOG.md` for user-visible changes.
- Ensure CI is green before requesting review.

## Code Style

- Follow standard Dart formatting (`dart format .`).
- Avoid breaking public API without documenting it.

## Reporting Issues

Use the repository issue templates and include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment (Dart/Flutter version, OS)
